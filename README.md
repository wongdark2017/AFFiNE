## 什么是 AFFiNE

[AFFiNE](https://affine.pro) 是一个开源的一体化工作空间。它将构建知识库所需的各种内容块整合在一起，支持维基、知识管理、演示文稿、数字资产管理等多种场景，为 Notion 和 Miro 提供另一种选择。

## 核心功能

**容纳各种内容块的真正画布，让文档与白板融为一体。**

- 许多编辑器都希望成为提升效率的创作画布，而 AFFiNE 支持将各种内容块放到无边界画布上：富文本、便签、嵌入网页、多视图数据库、关联页面、图形，甚至幻灯片，都可以自由组合。

**随时参与工作的多模态 AI 伙伴。**

- 撰写专业工作报告、将大纲转为生动的演示文稿、把文章整理成结构清晰的思维导图、梳理工作计划与待办任务，或用一句提示词绘图、编写应用和网页原型：[AFFiNE AI](https://affine.pro/ai) 帮助你将想法付诸实践。你也可以像使用 [AI 画布](https://affine.pro/blog/best-canvas-ai) 一样生成思维导图，开展头脑风暴。

**本地优先，支持实时协作。**

- 本地优先意味着数据保存在自己的磁盘上，由你掌握，不必完全依赖云端。AFFiNE 同时支持网页端与跨平台客户端之间的实时同步和协作。

**支持自托管，打造自己的 AFFiNE。**

- 你可以自由管理、自托管、派生并构建自己的 AFFiNE。插件社区与第三方内容块也在规划中。更多编辑器扩展能力可关注 [BlockSuite](https://blocksuite.io)，部署方式请参阅 [AFFiNE 自托管指南](https://docs.affine.pro/self-host-affine)。

## 灵感与致谢

“我们塑造工具，工具也在塑造我们。”一路走来，许多先行者为我们带来了启发：

- Quip 与 Notion 提出的“一切皆内容块”理念。
- Trello 的看板。
- Airtable 与 Miro 的无代码可编程数据表。
- Miro 与 Whimsical 的无边界可视化白板。
- Remote 与 Capacities 基于对象的标签系统。

这些应用的基础内容块有很多共同之处。我们希望在开源的基础上，提供类似 VS Code 的插件扩展方式，让贡献者能够自由定制，把喜爱的功能整合到一起，并进一步探索新的可能。

感谢你关注 AFFiNE，希望它能与你的工作和创作方式产生共鸣！🎵 更多信息请访问 [官方网站](https://affine.pro/)。

## 上游开源项目

感谢以下开源项目，它们为 AFFiNE 提供了重要支持：

- [BlockSuite](https://github.com/toeverything/BlockSuite)：💠 AFFiNE 背后的开源协作编辑器项目。
- [y-octo](https://github.com/y-crdt/y-octo)：🐙 原生、高性能、线程安全的 Yjs 无冲突复制数据类型（CRDT）实现，是 AFFiNE 客户端与服务端实现本地优先能力的核心引擎。
- [OctoBase](https://github.com/toeverything/OctoBase)：🐙 AFFiNE 背后的开源数据库，兼顾本地优先与协作能力，使用 Rust 编写，是一个轻量、可扩展的数据引擎。
- [Yjs](https://github.com/yjs/yjs)：为网页端状态管理与数据同步提供 CRDT 基础支持。
- [Electron](https://github.com/electron/electron)：使用 JavaScript、HTML 和 CSS 构建跨平台桌面应用。
- [React](https://github.com/facebook/react)：用于构建网页和原生用户界面的库。
- [napi-rs](https://github.com/napi-rs/napi-rs)：通过 Node-API 使用 Rust 构建编译型 Node.js 扩展的框架。
- [Jotai](https://github.com/pmndrs/jotai)：基于原子状态、灵活易用的 React 状态管理库。
- [async-call-rpc](https://github.com/Jack-Works/async-call-rpc)：轻量级 JSON 远程过程调用客户端与服务端。
- [Vite](https://github.com/vitejs/vite)：新一代前端构建工具。
- 其他上游 [依赖项目](https://github.com/toeverything/AFFiNE/network/dependencies)。

感谢开源社区提供功能强大、易于使用的库，让我们能够专注于产品逻辑的实现。我们也希望 AFFiNE 能为更多人带来易用的知识管理工具。
