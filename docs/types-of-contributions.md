# 贡献类型 :memo:

你可以通过多种方式为 AFFiNE 做贡献。本仓库是讨论与协作 AFFiNE 的地方！

### :mega: 讨论

讨论是我们对话的地方。

若需要文档 PR 排障帮助、有新想法，或想分享文档相关心得，欢迎加入 [discussions](https://github.com/toeverything/AFFiNE/discussions)。

### :lady_beetle: Issues

[Issues](https://docs.github.com/en/github/managing-your-work-on-github/about-issues) 用于跟踪贡献者可帮忙的任务。若 issue 带 triage 标签，说明我们尚未审阅，请不要开始做。

若在内容或网站上发现应更新处，请先搜索开放 issues 是否已有人报告。若是新问题，用 [模板](https://github.com/toeverything/AFFiNE/issues/new/choose) 开 issue。我们会在 issue 里讨论你想修复的问题。

### :hammer_and_wrench: Pull requests

[Pull request](https://docs.github.com/en/github/collaborating-with-issues-and-pull-requests/about-pull-requests) 是建议仓库变更的方式。合并后通常 24 小时内部署到线上站点。:earth_africa:
你可以 [创建新 PR](https://github.com/toeverything/AFFiNE/compare) 并查看 [当前 PR](https://github.com/toeverything/AFFiNE/pulls)。

### :question: 支持

我们是小团队，文档工作量很大。
也可在社交媒体与社群获取帮助——链接见 [README](../README.md)。

### :earth_asia: 翻译

AFFiNE 已国际化并提供多语言。本仓库源内容以英文撰写。我们通过外部本地化平台与社区合作翻译英文内容。更多信息见社区页与 [Discord](https://affine.pro/redirect/discord)。
