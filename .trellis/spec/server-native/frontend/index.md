## 如何填写这些规范

对每个规范文件：

1. 记录项目的**实际约定**（而非理想状态）
2. 附上代码库中的**代码示例**
3. 列出**禁止模式**及原因
4. 补充团队曾犯过的**常见错误**

目标是帮助 AI 助手与新成员理解**本项目**如何工作。
