# 修复工作区根数据缺失导致无限加载

## 目标与交付

用户要求基于最新 `dev-main` 创建新分支，产出修复方案。2026-09-08 用户确认方案并授权实施；本阶段交付代码修复和验证。

让无法完成初始化的工作区在有限时间内给出准确、可操作的提示。已登记的本地工作区缺少根文档时不再永久显示 Syncing；读取缓慢或来源尚未检查完成时，不宣称数据已丢失。

## 背景与已确认事实

- 已观察到本地工作区 ID 仍有登记、对应本地快照和增量为空、页面持续加载的故障。存储变空的触发原因尚未查明。
- `DocFrontend` 读到非空数据后才设置 `ready`；读取结束但无内容时可以出现 `loaded=true、ready=false`。锚点：`packages/common/nbstore/src/frontend/doc.ts:318`。
- 桌面和移动布局都只按根文档 ready 决定是否退出 fallback。锚点：`packages/frontend/core/src/desktop/pages/workspace/index.tsx:256`、`packages/frontend/core/src/desktop/pages/workspace/index.tsx:334`、`packages/frontend/core/src/mobile/pages/workspace/layout.tsx:112`。
- 本地工作区可能还在从 v1 存储迁移。现有 `synced` 不代表已完成来源检查，不能直接用于缺失判定。完整证据见 `research/code-map.md`。

## 产品要求

| 编号 | 要求                                                                                                         | 验收       |
| ---- | ------------------------------------------------------------------------------------------------------------ | ---------- |
| R1   | 本地首次读取成功但无有效根数据，且所需来源已检查、无待处理根更新时，显示“本地数据未找到”；不能宣称永久丢失。 | A1、A3、A5 |
| R2   | 建议等待上限为 30 秒；届时仍不确定，显示可操作的超时页。超时不能作为数据不存在的证据。                       | A2、A4     |
| R3   | 可识别的读取、解码、连接或同步错误显示加载失败；不直接显示可能含敏感信息的原始异常。                         | A4、A7     |
| R4   | 提供用户主动触发的重新加载、切换工作区、复制诊断和恢复建议。操作入口不依赖坏工作区初始化成功。               | A6、A7     |
| R5   | 桌面与移动布局复用状态规则，保留已就绪工作区、正常同步、原生平台和分享入口的既有语义。                       | A2、A3、A8 |
| R6   | 不自动初始化空根文档、删除登记、清库、重置同步元数据或上传本地数据。                                         | A1、A5、A6 |

## 验收标准

- **A1 本地缺失**：在合成测试数据中保留登记，去掉根快照与根增量；来源检查完成后显示错误页，其他文档、附件与登记保持不变。
- **A2 正常与空工作区**：存在合法根文档但目录为空时正常显示空列表；正常工作区和有缓存的离线云工作区正常进入。
- **A3 迁移不误判**：现代存储为空而 v1 有根数据时完成迁移并进入；旧存储读取未结束或失败时不显示本地数据未找到。
- **A4 有限等待**：Worker 无回应、来源检查无结果、慢云同步在 30 秒后显示超时页；后台读取继续，迟到有效数据自动恢复页面。
- **A5 并发**：根增量仍在应用时不判缺失；切换 id/flavour、卸载、重新加载后，旧 timer 和异步结果不污染当前页面。
- **A6 安全操作**：重新加载仅由点击触发；切换明确目标，不通过首页跳回坏工作区；异常状态不调用清库、删除、根初始化或 `resetSync()`。
- **A7 提示与诊断**：中英文、键盘操作可用；诊断只含工作区 ID、flavour、版本、阶段、稳定错误码和耗时，不含正文、标题、凭据、AI 会话或 URL 参数。
- **A8 跨入口**：桌面与移动布局一致；根已就绪时后台同步错误不遮挡内容；权限/分享路由不被误判成本地缺失。

## 范围外

- 本地存储变空的根因取证、自动数据恢复、事故现场 AI 会话导出。
- 改变本地/服务器工作区存储策略，自动开启云同步或新增备份系统。
- 自动创建空根文档、删除坏登记、修复任意 Yjs 语义损坏。
- 扩展所有导入/剪藏后台任务的等待协议；本次优先修复工作区页面入口，保留 `waitForDocReady` 合约。
- 未经后续要求，不推送或部署；不操作事故现场数据。
