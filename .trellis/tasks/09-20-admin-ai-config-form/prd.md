# AI 设置逐项表单

## 目标

用户要求把管理员设置中的 AI JSON 文本框拆成逐项输入，直接配置接口和密钥。

## 已确认现状

- AI 分组在 `packages/frontend/admin/src/modules/settings/config.ts`；对象配置默认显示 JSON 文本框。
- `use-app-config.ts` 已支持 `module/key/sub.path` 更新，会复制原对象并保留其他字段。
- 管理后台使用自己的 shadcn UI、Tailwind 和 `t()` 中文字典，生成的 `src/config.json` 不能手改。

## 需求与验收

1. OpenAI 兼容接口、OpenAI、Gemini、Anthropic、FAL、Unsplash、Exa 的配置均显示具名表单，AI 服务商配置无需手填 JSON。
2. 服务商分组提供简洁中文说明，接口地址、密钥、模型逐项填写；可选布尔配置使用开关。
3. 密钥默认遮挡，可主动显示/隐藏；各输入有可访问标签。
4. 原配置自动回填；修改单字段不丢失未知字段；现有保存、取消、分组状态保持有效。
5. AI 存储配置也使用逐项输入，按存储类型展示相关选项，保留既有未展示参数。
6. 相关设置测试、格式和静态检查通过；可运行时做浏览器视觉验证。
7. 用户已认可预览设计；各服务商标题、说明和输入框统一左对齐。
8. OpenAI 兼容接口的默认模型支持按当前未保存的密钥和接口地址获取模型列表，并从列表选择；保留手动输入。
9. 获取模型提供加载中、失败、空结果和重新获取状态；改变密钥或接口后旧结果失效，过期请求不能污染新配置。
10. 模型查询仅管理员可调用，由服务端请求模型服务；密钥只用于本次请求，不保存、不记录或回显。查询不需要默认模型，也不修改已保存配置。
11. 兼容接口提供“测试连接”，使用当前未保存地址、密钥、默认模型发起简短聊天请求。显示加载、成功/耗时或明确失败原因；改变配置后结果失效，不保存配置。

## 边界

不更改数据库及已有密钥。允许新增管理员模型发现与兼容接口连接测试接口；其他服务商的模型管理和连接测试暂不扩展。其它设置分组继续沿用原有编辑器。仓库中现存的其他用户改动保持原样。
