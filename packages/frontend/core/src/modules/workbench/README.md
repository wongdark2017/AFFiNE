# Workbench

```
 ┌─────────────Workbench─────-----──────┐
 |  Tab1 | Tab2 | Tab3            - □ x |
 │ ┌───────┐ ┌───────┐ ┌───────┐ ┌──────┤
 │ │header │ │header │ │header │ │      │
 │ │       │ │       │ │       │ │ side │
 │ │       │ │       │ │       │ │ bar  │
 │ │ view  │ │ view  │ │ view  │ │      │
 │ │       │ │       │ │       │ │      │
 │ │       │         │ │       │ │      │
 │ │       │ │       │ │       │ │      │
 │ └───────┘ └───────┘ └───────┘ │      │
 └───────────────────────────────┴──────┘
```

`Workbench` 是 AFFiNE 中的窗口管理器，包含主区域与右侧边栏区域。

`View` 是 workbench 下被管理的窗口。每个 view 有自己的历史（支持前进后退）与当前 URL。
View 按路由定义渲染内容。

更多行为与 API 见本模块源码。
